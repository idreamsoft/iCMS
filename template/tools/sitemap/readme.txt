## XML模板文件说明

### node.index.xml - 节点首页地图模板
- 输出500个顶级节点链接
- 每个顶级节点下包含：
  - 500个子节点链接
  - 500条内容链接
- 适用于网站节点结构的站点地图

### node.list.xml - 节点列表内容地图模板
- 输出500条内容链接
- 支持分页功能
- 适用于节点下的文章列表站点地图

### article.list.xml - 节点列表文章地图模板
- 输出500条内容链接
- 支持分页功能
- 适用于节点下的文章列表站点地图

### sitemap.index.xml - 站点地图索引模板
- 包含1000个站点地图链接
- 可与`node.list.xml`模板配合使用
- 用于站点地图索引提交

**注：所有模板均采用XML格式，便于程序解析和搜索引擎收录。**
